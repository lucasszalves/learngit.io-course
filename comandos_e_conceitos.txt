3 areas:

1 - working directory: arquivos em disco                                git commit -a |
    git add |                                                                 |    
            v                                                                 |
2 - staging area: arquivos selecionados para serem commitados                 |
    git commit |                                                              |
               v                                                              v
3 - repositorio: arquivos commitados e historico gravado

HEAD: ponteiro para o commit atual



COMANDOS:
git log: mostra os commits, o hash completo e a mensagem
git log --stat: mostra quais arquivos foram modificados
git show <hash>: ver as linhas modificadas
git log --oneline: resumos dos commits, mostra só as mensagens e uma versão curta do hash (que pode ser usada pra acessar o commit)

git restore --staged <file>: unstageia arquivo
git restore <file>: desfaz alterações do arquivo MODIFIED, volta para o estado do último commit (PERDE AS MODIFICAÇÕES NÃO COMMITADAS), tipo um ctrl+z. não funciona para arquivos staged (usar flag --staged)

git commit --amend -m 'mensagem corrigida': corrigir mensagem do ÚLTIMO commit
git commit --amend --no-edit: não muda a mensagem do commit, só adiciona os arquivos STAGED ao último commit
git reset HEAD~1: volta um commit, e as modificações do último commit (que foi deletado), vão pro working directory (como se fosse voltar no tempo para logo antes de dar o commit)

git merge <incoming branch>: feito na branch que irá receber as modificações da incoming branch
